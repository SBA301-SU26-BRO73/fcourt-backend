# Báo cáo cuối kỳ

Thư mục này chứa báo cáo cuối kỳ của dự án. Bản chính thức `FCourt_Report_MSS301.docx` được đưa vào git. Các bản nháp và file PDF xuất ra vẫn không đưa vào git (quy tắc `docs/report/*` trong `.gitignore` ở thư mục gốc), hãy tải lên ổ đĩa chung của nhóm.

## Quy ước đặt tên file

```
FCourt-Report-<version>-<yyyymmdd>.docx
FCourt-Report-<version>-<yyyymmdd>.pdf
```

Ví dụ: `FCourt-Report-v1.0-20261120.docx`. Bản PDF xuất ra dùng cùng tên gốc. Không đưa secret, thông tin xác thực hoặc dữ liệu cá nhân vào báo cáo.
